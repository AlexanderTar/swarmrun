# Logos

- `app-icon.png`: the app icon (512), the macOS Liquid Glass render Swarm ships everywhere: the Mac app, the board's favicon and home-screen icon, the relay's offline page and the site. Generated by `apps/menubar/scripts/build-icon.sh` from the Icon Composer source; never edit it by hand. Use as is.
- `app-icon.svg`: the flat vector drawing of the app icon (1024), full colour with the brand gradient. Only for places that need a vector; anywhere the icon is shown, use `app-icon.png`.
- `glyph.svg`: the single-colour mark (24). In code it takes `currentColor`; shown here as an image it renders in its default ink. Use it in `--neutral-50` on dark surfaces.
